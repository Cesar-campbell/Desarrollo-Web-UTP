# Desarrollo Web UTP

Repositorio de prácticas y laboratorios del curso de Desarrollo Web, usando **PHP, HTML y CSS**.

## 📁 Contenido (en orden de subida)

### 1. Introducción a PHP - Variables y operaciones
- [`Variable.php`](Variable.php) — Ejemplo de variables y salida dinámica con `echo`.
- [`Operaciones.php`](Operaciones.php) — Operaciones matemáticas básicas (suma, resta, multiplicación, división, módulo, potenciación, redondeo).
- [`Embebido.php`](Embebido.php) — Primer ejemplo de código PHP embebido dentro de HTML.
- [`Calculadora.php`](Calculadora.php) — Calculadora básica con formulario y redondeo de resultados.
- [`Circunferencia.php`](Circunferencia.php) — Cálculo de área y perímetro de un círculo a partir del radio.
- [`Convertidor.php`](Convertidor.php) — Convertidor de pulgadas a centímetros.
- [`Formulario.php`](Formulario.php) — Formulario HTML que envía datos a `pagina2.php`.
- [`pagina2.php`](pagina2.php) — Procesa los datos del formulario (nombre y edad) y valida mayoría de edad.

### 2. phpinfo() y configuración
- [`info.php`](info.php) — Muestra la información de configuración de PHP (`phpinfo()`).

### 3. Estructuras de control, arrays y validaciones
- [`For.php`](For.php) — Ejemplo de bucle `for`.
- [`Foreach.php`](Foreach.php) — Ejemplo de bucle `foreach` sobre un array de animales.
- [`Equipos.php`](Equipos.php) — Recorrido de un array asociativo (equipo de fútbol) con `foreach`.
- [`Random.php`](Random.php) — Generador de números aleatorios con `do...while`.
- [`EjemploEmpty.php`](EjemploEmpty.php) — Ejemplo de uso de `isset()`.
- [`EjemploHTML.php`](EjemploHTML.php) — Ejemplo de `htmlspecialchars()` para escapar HTML.
- [`EjemploValidacion.php`](EjemploValidacion.php) — Validación de variables con `isset()`.
- [`Ejemplo.html`](Ejemplo.html) — Página HTML de ejemplo (MDN).
- [`Brave.html`](Brave.html) / [`brave-style.css`](brave-style.css) — Página de ejemplo con estilo propio inspirado en Brave Browser.

### 4. Proyecto con sesiones — IA básica en PHP
- [`IA.php`](IA.php) — Chat con IA básica usando `$_SESSION` para mantener el historial de conversación.
